# Global operational work

Global Tasks uses Work and Approvals as separate main tabs, retaining the Sales tasks entry point. Work combines project tasks, daily output reviews, procurement orders, dispatch/receipt, snags and handovers. Each row identifies its source and opens that source's existing project action screen. It never stores a second status or bypasses its action/state contract.

Columns: work, type, project, state, responsible person, due date and action. Views: My work, Open work, All work. Search and pagination operate on authorized records on the server, ordered by due date and stable source identity. Unassigned review work is visible to eligible reviewers, excluding the original author. No evidence contents, commercial rates or client-private details are copied into this queue. Loading/errors remain distinct from an empty queue; retries preserve filters.

This extends the existing RFA/amendment queue. It does not by itself complete advanced board ranking, WIP policies, workflow automation or every blueprint source. These remain explicit acceptance items.
