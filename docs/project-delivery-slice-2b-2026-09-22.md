# Slice 2B — material-backed installation output

Local only. Site task → Materials → Set usage basis records material units per one output unit, the task's output unit, planner and evidence. Example: one chair per installed chair; four brackets per installed cabinet. No conversion is inferred. A basis is fixed once material has been issued or site output has been reported; later corrections need a controlled reversal workflow.

For tasks opting into this control, every directly linked company/client material needs a basis. Available installation output is the minimum net quantity issued to that task divided by its material usage basis, capped by planned output. Pending QC, warehouse stock, reservations and issues to other teams do not count as site custody. Factory receipt controls continue independently. Start needs positive remaining backed output; approving a daily report must stay within the cumulative backed limit. Unused returns cannot remove material supporting approved output. Unit changes invalidate the basis until reconciled.

UI columns: material, source, required, stock, allocated, issued, usage basis, backed output and contextual action. Uses existing grid, record dialog and execution API (`material_output_basis`). Legacy tasks without a basis keep their existing rules; this is not a claim that all historical task output is material-controlled. Vendor service quantities, cross-location proof of delivery, waste during installation, basis reversals and client acceptance remain separate work.

Validation: eight focused domain tests pass, including pending receipt → independent QC → site issue → cumulative installation approval, missing basis, changed units, limiting material, other-team stock, unused returns and start readiness. Both typechecks pass. Two browser checks pass on desktop/mobile for the task materials grid, capacity summary, keyboard dialog and RTL overflow; mobile screenshot inspected. Targeted lint passes for the shared web export and browser test. Existing workspace component lint issues documented in 2A remain. No live database integration or deployment performed. The backed-output value is a task summary, rather than a per-material grid column.
