# Module 03 — Workspace readiness (Home slice; paused)

This file retains its original filename for existing links. Module 02 is Connections in the product implementation plan. Home is paused at the user's request; this slice does not change the agreed module order. Resources (Module 04) is the next business-module design pass; live Connections acceptance remains outstanding.

Home introduces one compact setup checklist. A selected item reveals its purpose and next action alongside the list; mobile stacks the detail below it. The checklist can be hidden and reopened, with that preference scoped to the current user and workspace on this device.

Items: company/document identity, regional defaults, people, existing data, quotation templates, and connections. Completion is based on loaded records; opening a link never completes an item. Unknown state remains unknown. Optional items do not block work.

Data dependencies: company profile for address and regional settings; members for staff/invitations; integration connections for authorized accounts. Import history and quotation readiness need their own backend evidence before reporting completion. Initially those entries remain action items, without invented completion.

Import entry: choose clients/contacts or materials/catalog. Existing catalog import is reused through Catalog. Client import belongs to Module 05, after Resources: upload CSV/XLSX, map name/contact/email/phone/country/address/owner/notes, validate required identity, review duplicate policy, import transactionally and return counts/error download. Until that API exists, its chooser explicitly identifies availability and does not accept a file it cannot save.

Visual contract: one title, compact type hierarchy, brand-green active state, neutral field surfaces, 16–18px Lucide icons, consistent controls, no enclosing bordered dashboard card. Logical CSS supports RTL. Keyboard focus is visible; no required motion.
